# NIMBY Rails Speed Limit Patch

[English](README.en.md)

将特定 Windows 版本 NIMBY Rails 的**轨道模组加载上限**从 600 提高到 1200 km/h。提供备份、精确版本校验和恢复功能。仅依赖 Python 标准库，无第三方依赖。

## 状态与范围

- 已完成静态反汇编分析、实际文件补丁写入与校验、转换/还原自测和不兼容文件拒绝测试。
- **尚未完成游戏内超过 600 km/h 行驶验证。**这是实验性补丁，欢迎报告测试结果。
- 不是一键把所有轨道改成 1200。每种轨道各层的 `[TrackLayer] max_speed` 仍决定其速度；原版 350 轨道仍为 350，写有 900 的模组可以按 900 加载。
- 不修改车辆、动力、弯道限速或自定义限速界面。自定义限速设为 0 可取消额外限速；车辆还需有足够最高速度、动力与加速距离。
- 不涉及 Steam 验证、DRM 或其他访问控制。

## 支持的版本

仅支持以下**原始程序 SHA-256**（未确认对应的官方版本号）：

```text
2668b2580d890c0c2b6d0b7befb8069891c15f39ea12917ac8fa26bd06a14eb9
```

1200 补丁后的 SHA-256：

```text
4f20a8b769e6b313bceeaf11e3b6b79debaa7efcea6d3e942106f60e57bc1722
```

更新或其他补丁导致文件不匹配时，工具将拒绝修改。不要直接复用偏移来适配新版本。

## 使用

Windows，Python 3.9 或更新版本。先退出游戏。下载本项目源码，命令中的路径替换为你的游戏安装目录：

```powershell
py -3 patch.py status --game-dir "D:\Games\NIMBY Rails"
py -3 patch.py selftest --game-dir "D:\Games\NIMBY Rails"
py -3 patch.py apply --game-dir "D:\Games\NIMBY Rails"
```

也可将本项目文件夹放进游戏安装目录后双击 `Apply-1200.cmd`。启动器使用系统的 Python，不依赖 Nimby3D。

应用时在游戏目录生成 `NimbyRails.exe.speed-limit-original.bak`。请保留；不要上传备份。若此前用过本地旧版补丁，本工具可识别同样的补丁结果并生成经过原始哈希验证的恢复备份。

重新启动游戏，在新建测试地图用允许超高速的列车和轨道、长直线验证。自定义限速为 600 时需取消。建议使用存档副本测试。

## 恢复

退出游戏后运行，或双击 `Restore-600.cmd`：

```powershell
py -3 patch.py restore --game-dir "D:\Games\NIMBY Rails"
```

恢复会校验备份和当前程序。Steam 更新或验证文件可能覆盖补丁；更新后的程序不能使用旧补丁或旧备份强行覆盖。

## 原理

轨道模组加载器读取 `max_speed`，将其限制在 10～600 km/h 后除以 3.6。此版本中加载器指令 RVA 为 `0x4034DB`，独立 double 常量 RVA 为 `0xAAD1A8`。完整静态反汇编中此常量只有加载器一处引用。

补丁仅将这个 double 常量由 600.0 改为 1200.0，不改共享的 float 600 常量。工具读取 PE 节表将 RVA 转为文件偏移，验证加载器签名和整个原程序哈希后才写入。写入使用同目录临时文件替换并核验结果。

`selftest` 需要本机合法安装的兼容游戏文件；仅在内存中检查转换、还原和修改版本拒绝，不启动游戏，不改写文件。
